AI Assistant – API Integration

A simple AI-powered chatbot that generates responses to user prompts using an AI API.

Features

- Interactive chat interface
- User prompt submission
- AI-generated responses
- Error handling
- Responsive design

Tech Stack

- Next.js
- React
- TypeScript
- Google Gemini API
- Node.js

Setup

1. Clone the repository.
2. Install dependencies:
   npm install
3. Add your API key to the ".env" file:
   GEMINI_API_KEY=your_api_key
4. Start the development server:
   npm run dev

Security

API keys are stored in environment variables and are never exposed on the frontend.
